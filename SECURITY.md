# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in auto-stack, please report it privately using [GitHub's private vulnerability reporting](https://github.com/mistakenot/auto-stack/security/advisories/new).

Do not open a public issue for security vulnerabilities.

## What to expect

- Acknowledgement within 3 business days.
- A fix or mitigation plan within 14 days for confirmed issues.
- Credit in the release notes (unless you prefer otherwise).

## Scope

This policy covers the auto-stack CLI tools and their release artifacts. It does not cover the infrastructure hosting the repository (GitHub).

# (Auto)nomous Coding Stack

Started with a frustration of "what the hell are my agents doing?"

A set of simple interlinking tools to help me become a better agentic coder.

   AI Coding  >>>  auto-etl  >>>. auto-search  >>>  auto-reflect >>> auto-skill
   <<< --- <<< --- <<< --- <<< --- <<< --- <<< --- <<< --- <<< --- <<< --- 

   All controlled by auto-watch

## 1. Install

```bash
curl -fsSL https://raw.githubusercontent.com/mistakenot/auto-stack/main/install.sh | bash
```

Or set a custom install directory: `INSTALL_DIR=/usr/local/bin curl -fsSL ... | bash`

## Development Setup

```bash
make install-hooks   # set up pre-commit hooks (format, lint, beads sync)
```

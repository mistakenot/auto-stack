## Goal

Turn clustered observations into playbook changes through a deterministic, gated CLI step —
the boundary between cheap observation capture and durable rules. The LLM (the calling skill)
decides clustering and drafts rule text; the CLI only validates, gates on evidence, dedupes,
and persists. Plus explicit `rule promote` / `rule retire` verbs.

## Commands

### `auto reflect consolidate <json|->`
Accepts a **delta document** (positional JSON or `-` for stdin), mirroring `feedback`'s input
style. Deltas:
```json
{ "deltas": [
  { "op": "create-draft", "use_when": "...", "content": "...", "causal_note": "...",
    "domain": ["go"], "type": "soft", "observation_ids": ["ob-..","ob-.."] },
  { "op": "attach-evidence", "rule_id": "r-..", "observation_ids": ["ob-.."] },
  { "op": "merge", "rule_ids": ["r-..","r-.."], "into_use_when": "...", "observation_ids": [...] },
  { "op": "deprecate", "rule_id": "r-..", "reason": "..." }
] }
```
Deterministic gates (CLI, no LLM):
- **Evidence threshold:** `create-draft` requires `observation_ids` covering **≥2 distinct
  sessions** (resolve each `ob-` id → its evidence session ids via the event log). `--force`
  bypasses; an observation of `severity: high` (incident) auto-bypasses for that delta.
- **Dedupe:** for each `create-draft`, run the existing matcher (`rules.MatchRules`) with the
  candidate `use_when`; if an existing non-stale rule scores above a high threshold, refuse
  that delta with a hint to use `attach-evidence` instead (do not silently merge).
- **Conflict flag:** if `create-draft`/`merge` domain overlaps an existing rule whose content
  looks contradictory, do not block — emit it in a `conflicts` array in the output for human
  review.
- `--dry-run`: compute and report all the above, write nothing.
- Created rules enter `lifecycle: draft`, carry `observation_ids` provenance, and append the
  normal `rule_created` event **plus** a new `consolidation` event linking observation ids →
  rule id (this is what flips 1.3's `--unconsolidated` filter).

Output JSON: `{ "applied": [...], "skipped": [{delta, reason}], "conflicts": [...] }`.

### `auto reflect rule promote <r-id>` / `rule retire <r-id>`
- `promote`: `draft → confirmed`. Refuses (exit 1 + hint) when the rule's provenance covers
  **<2 distinct sessions** unless `--force`. Implemented as a `rule_edited` lifecycle delta
  (reuse the edit path), so it's one versioned event.
- `retire`: any → `stale`. Always allowed.

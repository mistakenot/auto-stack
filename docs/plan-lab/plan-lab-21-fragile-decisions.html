1 · Decisions ranked by fragility

A decision is fragile when it is hard to undo and a lot of the plan hangs off it. Blast radius is counted from the plan model's links; reversibility is a judgement read from the plan text, so it is marked assessed. Click a row for its footprint.

fragility = reversibility × blast radius  ·  reversibility (assessed): one-way door = 3, two-way door = 1  ·  blast radius = |ACs| + |goals| + |files| + |existing files| — ACs are the decision's own acs; goals are its goals ∪ each AC's goal; files are every file whose acs overlap those ACs; existing = those files with change edit/context/delete (counted twice: touching code that already exists costs more).

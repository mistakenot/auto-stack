# Solution: Task 013

## Approach

Scaffold `auto-ui/` as a standard auto-* package whose one domain command, `serve`, runs an HTTP
server that exposes a JSON `/api/*` surface and serves a no-build Preact + htm SPA. A build-tag
split decides where the static files come from: embedded (`//go:build !dev`) for the shippable
single binary, or live from disk (`//go:build dev`) for the edit→refresh loop. The SPA uses
hash-based routing so all view + view-state lives in `location.hash` and survives reload.

1. **Package skeleton** — create the full auto-* layout (`cmd/autoui`, `internal/app`,
   `internal/cli/{root,init,doctor,quickstart,docs,update,serve}`, `internal/config`,
   `internal/server`). Match `auto-graph`/`auto-skill` conventions exactly (ExitError, `app.New`,
   `version.Version`, JSON-to-stdout).
2. **Static asset package with build-tag split** — `web/static/` holds the SPA; `web/embed_prod.go`
   (`//go:build !dev`) embeds it via `//go:embed all:static`; `web/embed_dev.go` (`//go:build dev`)
   returns `os.DirFS` over the same folder. Both expose `web.FS() fs.FS` and `web.Mode string`.
3. **HTTP server** — `internal/server` builds an `http.ServeMux`: `/api/hello` returns JSON;
   `/` is `http.FileServer(http.FS(web.FS()))`. Hash routing means no deep server paths and no SPA
   fallback handler is needed (`GET /` naturally serves `index.html`).
4. **`serve` command** — binds `--port` (default 8080), starts `http.Server`, and shuts down
   gracefully on `cmd.Context()` cancellation (SIGINT/SIGTERM). Logs the URL + mode to **stderr**.
5. **Frontend (Preact + htm, no build)** — `index.html` carries the import map (preact,
   preact/hooks, htm/preact, plus the `preact/compat` → preact alias kept ready); `app.js` mounts
   the app; a tiny `router.js` reads/writes `location.hash`. Two views (Home, Dashboard); a counter
   whose value is encoded in the hash query; Dashboard fetches `/api/hello` and renders it.
6. **Monorepo wiring** — add `auto-ui` to root `Makefile` (PROJECTS + build/dist/install targets)
   and the sub-projects table in root `CLAUDE.md`; add `auto-ui/CLAUDE.md`.
7. **Verification** — Go tests for the server contract; **agent-browser conformance run** for the
   browser-only ACs (render, navigate, fetch-render, and dev-mode edit-file-then-reload).

### Key outlines

`web/embed_prod.go` (default build):
```go
//go:build !dev

package web

import (
	"embed"
	"io/fs"
)

//go:embed all:static
var content embed.FS

// Mode reports where assets are served from (for diagnostics).
const Mode = "embed"

// FS returns the SPA file system rooted at the static dir.
func FS() fs.FS {
	sub, err := fs.Sub(content, "static")
	if err != nil {
		panic(err) // embed.FS is compile-time known; sub cannot fail
	}
	return sub
}
```

`web/embed_dev.go` (`-tags dev`):
```go
//go:build dev

package web

import (
	"io/fs"
	"os"
)

const Mode = "disk"

// FS serves live from disk so edits need only a browser refresh.
// Path is relative to the module root (run from auto-ui/).
func FS() fs.FS { return os.DirFS("web/static") }
```

`internal/server/server.go`:
```go
package server

import (
	"encoding/json"
	"io/fs"
	"net/http"
)

func New(fsys fs.FS, mode string) http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("/api/hello", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		_ = json.NewEncoder(w).Encode(map[string]string{
			"message": "hi from go",
			"mode":    mode,
		})
	})
	mux.Handle("/", http.FileServer(http.FS(fsys))) // GET / -> index.html
	return mux
}
```

`internal/cli/serve.go` (settings-derived default, graceful shutdown via `cmd.Context()`):
```go
func newServeCmd(application *app.App) *cobra.Command {
	var port int
	cmd := &cobra.Command{
		Use:   "serve",
		Short: "Serve the auto-ui dashboard locally",
		Args:  cobra.NoArgs,
		RunE: func(cmd *cobra.Command, args []string) error {
			// If --port was not set, fall back to the configured Settings.Port
			// (mirrors auto-graph/internal/cli/code_graph.go:21-22 LoadGraphSettings).
			if !cmd.Flags().Changed("port") {
				if p, err := config.UISettingsPath(); err == nil {
					if s, err := config.LoadUISettings(p); err == nil && s.Port != 0 {
						port = s.Port
					}
				}
			}
			handler := server.New(web.FS(), web.Mode)
			srv := &http.Server{Addr: fmt.Sprintf(":%d", port), Handler: handler}
			go func() {
				<-cmd.Context().Done()
				_ = srv.Shutdown(context.Background())
			}()
			fmt.Fprintf(application.Stderr, "autoui serving on http://localhost:%d (assets=%s)\n", port, web.Mode)
			if err := srv.ListenAndServe(); err != nil && !errors.Is(err, http.ErrServerClosed) {
				return &ExitError{Code: 1, Err: err}
			}
			return nil
		},
	}
	cmd.Flags().IntVar(&port, "port", 8080, "port to serve on (overrides settings.json)")
	return cmd
}
```

Precedence: explicit `--port` flag > `Settings.Port` from `~/.auto/ui/settings.json` > built-in
default 8080. `config.LoadUISettings`/`UISettingsPath` follow the auto-graph
`LoadGraphSettings`/`GraphSettingsPath` pattern.

`web/static/router.js` + `app.js` (state-in-URL sketch):
```js
// router.js — hash shape: #/<view>?<query>
export function parseHash() {
  const raw = location.hash.replace(/^#/, "") || "/";
  const [path, qs] = raw.split("?");
  return { view: (path.replace(/^\//, "") || "home"), params: new URLSearchParams(qs || "") };
}
export function setHash(view, params) {
  const qs = params.toString();
  location.hash = `/${view}${qs ? "?" + qs : ""}`;
}
export function onRouteChange(cb) { addEventListener("hashchange", cb); }

// app.js — counter value lives in the hash (?n=), Dashboard fetches /api/hello
import { render } from "preact";
import { useState, useEffect } from "preact/hooks";
import { html } from "htm/preact";
import { parseHash, setHash, onRouteChange } from "./router.js";
// App reads parseHash() for {view, params}, renders Home/Dashboard,
// writes state back with setHash(), and re-renders on onRouteChange().

**Why agent-browser for AC-1/2/3/5:** the frontend is browser-run Preact+htm with no build step,
so rendering, hash routing, and dev-mode hot-reload cannot be exercised by Go tests. agent-browser
drives a real browser to load the page, assert the DOM rendered, click navigation and check
`location.hash` + restored state, trigger the fetch and read the response in the DOM, and — for
AC-2 — edit a `web/static` file while `serve -tags dev` is running, reload, and confirm the change
is visible without restarting Go. The full script is the `conformance.md` artifact.

## Out of Scope

- Any real dashboard feature / reading actual auto-stack data (sessions, docs, graph). Trivial demo only.
- Production concerns: minification, optimization, auth, TLS, CDN pinning / offline vendoring.
- Hot Module Replacement — refresh is the loop; not building it.
- Multi-user / remote deployment. Local-dev / internal only.
- **autoenv per-worktree port allocation** — `serve` takes a fixed `--port` (default 8080) for now;
  wiring the port from autoenv is a later task.
- **SPA history-API routing / server fallback** — hash-only by decision (Q3); no fallback handler.
- Persisting UI state anywhere other than the URL (no localStorage/server session).

## Rejected Alternatives

- **Vue 3 global build / React + Babel** — rejected in requirements (Q1) in favor of Preact + htm
  (zero transpile, smallest loop, React escape hatch via `preact/compat`).
- **Vendoring framework files into `web/vendor/`** — deferred (Q4); CDN import map is simpler for
  this first proof. Revisit for offline/reproducible builds.
- **HTML5 history routing with a Go SPA fallback handler** — rejected (Q3); hash routing carries
  state for free and needs no server route matching, so the fallback handler is unnecessary.
- **Embedding `web/` at the module root / in `cmd`** — `go:embed` can't reference parent dirs, so a
  dedicated `web` package co-located with `static/` is the clean home for the build-tag split.
- **Minimal single-`main.go` spike** — rejected in requirements (Q2); full skeleton chosen so the
  package is consistent with the rest of auto-stack from day one.
- **Go-only / headless tests for rendering** — insufficient; a no-build browser frontend must be
  verified in a real browser, hence agent-browser conformance.

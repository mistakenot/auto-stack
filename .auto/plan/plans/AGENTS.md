# .auto/plan/plans

Each `NNN-name/` folder here is a plan managed by `auto plan`: one `graph.json` per plan.
Don't edit `graph.json` by hand. Change plans with `auto plan` (add, update, link, …) and read them
with `auto plan list`, `show`, `get` and `search`.

Run `auto plan quickstart` for the workflow and `auto plan docs` for the full reference.
